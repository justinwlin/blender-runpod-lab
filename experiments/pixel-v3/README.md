# Pixel v3: rig-ready mascot and the "golden hour" short

Everything needed to rebuild the v3 Pixel model, rig, animation, set and the 26 s 1080p short: all `bpy` scripts, render settings, pod and render-farm scripts, and the ffmpeg finishing commands. No media and no `.blend` files are in git (see [Files kept outside git](#files-kept-outside-git)).

- [PROCESS.md](PROCESS.md): how it was made, in order, and what failed
- [V3_RESULT.md](V3_RESULT.md): the result and an honest list of what still looks amateur

Reference art: [justinwlin/pixel-mascot](https://github.com/justinwlin/pixel-mascot).

## Verified vs not verified

**Verified (run and measured on 13-14 Nov 2026):**

- Every script in `scripts/v3/` and `scripts/base/` ran on the pods or the box and produced the delivered film, in the versions listed below.
- Frame times, pod prices and the render split in [Costs and timings](#costs-and-timings) are from the render logs and the Runpod API.
- All 624 frames were opened and checked before encoding.

**Not verified:**

- **A clean end-to-end rebuild from this folder has not been run as one pass.** The steps below are the commands that were run, but spread over a long session with fixes in between.
- **Hunyuan3D versions.** The meshes were generated by an earlier session; the `diffusers` / `transformers` versions on that pod were never read before it was terminated. The pin below is the intended one, not a confirmed one.
- **Playback.** The motion was judged from stills and contact sheets, not by watching the film.
- **The delivered film is not byte-reproducible from these scripts.** Only shot 2 (frames 60-89) was rendered after the last eyelid change. The scripts here are the final version, so a rebuild gives the final eyelids in every shot, which differs slightly from the delivered film in the blink frames of other shots.
- Paths: the pod-side helpers (`run_gates.sh`, `run_cut.sh`, `farm.sh`) assume a working directory of `/workspace/pc` on each pod and SSH aliases written by `pod.sh`.

Experiments that were tried and dropped are listed at the end.

## Render settings

| Setting | Value |
| --- | --- |

| Colour | AgX, look "AgX - Medium High Contrast", exposure 0 |
| Motion blur | on, shutter 0.5 |
| Depth of field | on, f/4 to f/8 per shot, focus on a face bone (ball for the paw insert) |
| Light paths | 8 max bounces, 0 volume bounces, seed 7, persistent data |
| Output | 8-bit PNG per frame |
| Lenses | 35 / 85 / 50 / 40 / 100 / 35 / 50 / 35 mm over eight shots |

All of these are set at the bottom of `scripts/v3/film.py`; `render.py` only chooses frames, sample count and scale.

Finishing (`scripts/v3/post.sh`, ffmpeg): highlights above 0.72 blurred (sigma 22) and screened back at 0.32 opacity, `eq` contrast 1.06 / saturation 1.10 / gamma 1.02, a warm `colorbalance`, vignette, grain (`noise=alls=6`), title overlay fading in at 23.4 s, 0.5 s fade in and 0.75 s fade out, H.264 `-preset slow -crf 15`, yuv420p.

## Rebuild, step by step

Work in a directory that has this folder's `scripts/` (so `scripts/base/` and `scripts/v3/`), and `out/`. Use absolute paths for Blender outputs.

### 1. Image to 3D: the Hunyuan head and body (GPU pod)

```sh
git clone https://github.com/Tencent/Hunyuan3D-2 && cd Hunyuan3D-2 && pip install -e .
pip install 'diffusers==0.31.0' 'transformers==4.46.3'      # intended pin, see "Not verified"
git clone https://github.com/justinwlin/pixel-mascot /workspace/pixel-mascot
mkdir -p /workspace/in /workspace/out
HF_HUB_ENABLE_HF_TRANSFER=1 python3 /path/to/scripts/base/gen.py
```

`gen.py` crops the front and side views from the original sheet and the back view from the turnaround sheet, removes the white background, and runs the multi-view pipeline for three view combinations and two seeds. Copy `/workspace/out/*.glb` to `out/glb/` and `/workspace/in/*.png` to `out/in/`. The mesh used is `B_front_right_back_s12345.glb`. About 30 s per mesh on an L40S.

### 2. Label maps and the v2 body (colour and shape source for the v3 head)

```sh
python scripts/base/make_labels.py out/in/ out/labels/
mkdir -p v2/sheet
blender -b -P scripts/base/build_pixel.py -- out/glb/B_front_right_back_s12345.glb out/labels "$PWD/v2" gpu
```

This gives `v2/pixel-calico.blend`: the Hunyuan surface with palette colours per vertex. v3 reads it for the head shape and as a colour fallback.

### 3. v3 textures, model, UVs, bake, eyelids, skeleton

```sh
python scripts/v3/make_textures.py out/labels/ out/v3/tex/
blender -b v2/pixel-calico.blend -P scripts/v3/build_v3.py -- out/labels "$PWD/out/v3/tex" "$PWD/v3" gpu
blender -b v3/pixel-v3.blend -P scripts/v3/gate_model.py -- "$PWD/v3/gates"      # turnaround in 3 poses + wireframe
```

`build_v3.py` writes `v3/pixel-v3.blend` (textures packed) and `v3/tex/atlasA.png`, `atlasB.png`, `maskA.png`. About 3 minutes on an RTX A5000.

### 4. Set, lights, cameras, animation

```sh
python scripts/v3/make_title.py out/v3/tex/title.png <serif.ttf> <sans.ttf>     # Fraunces + Inter were used
cp <any square picture> out/v3/tex/portrait.png                               # the framed picture; the v2 hero render was used
blender -b v3/pixel-v3.blend -P scripts/v3/film.py -- "$PWD/out/v3/tex" "$PWD/v3/film.blend"
```

`film.py` is the single clock: shot list, beat frames, cameras, sun animation and every keyframe are in it.

### 5. Gates before the full render

```sh
blender -b v3/film.blend -P scripts/v3/render.py -- "$PWD/v3/gates/shots" 30,75,104,140,200,270,326,372,404,490,560,610 samples=64 scale=50
blender -b v3/film.blend -P scripts/v3/render.py -- "$PWD/v3/gates/check" 0:624:6:0 samples=16 scale=25 novol   # dense whole-cut check
blender -b v3/film.blend -P scripts/v3/render.py -- "$PWD/v3/gates/final_test" 200,326 samples=192 scale=100    # timing
```

`run_gates.sh` and `run_cut.sh` chain these on a pod.

### 6. Pods and the render farm

```sh
export RUNPOD_PERSONAL_API_KEY=...  RUNPOD_TEMPLATE_ID=...     # the blender-5.0.1 template
sh scripts/v3/pod.sh create pixel-calico-r2 && sh scripts/v3/pod.sh wait pixel-calico-r2 pixr2    # repeat per pod
mkdir -p out/v3/blend && cp v3/film.blend out/v3/blend/film.blend
sh scripts/v3/farm.sh push      # scene + scripts to every pod, prints a checksum per pod
sh scripts/v3/farm.sh split     # deal the frames not yet rendered anywhere out as per-pod lists
sh scripts/v3/farm.sh start     # one detached Blender per pod
sh scripts/v3/farm.sh status
sh scripts/v3/farm.sh pull      # copy finished frames to out/v3/frames/ (repeat; skips files still being written)
```

`farm.sh` reads the pod list from `PODS` (SSH aliases) and gives the pod named in `SLOW` one turn per round and the others two. It never deletes anything; re-running `split` and `start` re-deals whatever is still missing.

### 7. Verify and finish

```sh
python - <<'PY'
import glob
from PIL import Image
for f in sorted(glob.glob('out/v3/frames/*.png')): Image.open(f).load()     # raises on a truncated file
PY
sh scripts/v3/post.sh out/v3/frames out/v3/tex/title.png pixel_golden_hour.mp4
```

## Experiments that were dropped

These were tried during the run and are not part of the final scripts, or are still in them only as comments:

- **Animating the fused, seated Hunyuan mesh** (v1/v2, bone heat on a proxy). It smears; this is why v3 exists. Scripts: `scripts/pixel_calico/` at the repo root.
- **Leg tops as soft thighs outside the body.** Read as lumps, then as white cups with a rim. Replaced by tucking the leg tops under the torso surface.
- **A torso with a raised chest and tucked rear.** Read as a broken waist.
- **Body calico from high-detail noise with speckles.** Read as splatter; replaced by one low-frequency noise.
- **Eyelids: all black, then coloured from the fur straight above the eye.** Both read as dark bulges when closed; the final version samples the nearest fur around the eye.
- **f/2 close-ups at 100 mm.** A few millimetres of focus on a 23 cm subject.
- **A fixed every-Nth split across pods of different speeds.** Replaced mid-render by explicit per-pod lists.
- **Rigify, a hair groom, Hunyuan3D-Paint, a UV bake of the v2 body, a 4K master, sound.** Planned in the research notes, not attempted.
